# Pomodoro Focus

A minimal Pomodoro timer with a glassmorphism UI, photo backgrounds, background music and end-of-phase chimes.

## Features
- Focus / short break / long break cycle (4 focus sessions per round)
- Adjustable durations, daily pomodoro counter
- Background music and selectable chime
- Keyboard shortcuts: Space (play/pause), R (restart), S or → (skip)
- Responsive, works offline, state saved in `localStorage`

## Run
Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```
